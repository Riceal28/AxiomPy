# AxiomPy 0.2.1

AxiomPy 0.2.1 fixes the broken 0.2.0 portable package and adds the requested
preset, container, audio-stream and mouse-wheel UI behavior.

## Fixed

- The Windows archive now contains the real FFmpeg, FFprobe and FFplay binaries.
  The 0.2.0 archive accidentally bundled Chocolatey shims, which failed with
  `Cannot find file at '..\lib\ffmpeg\tools\ffmpeg\bin\ffmpeg.exe'`.
- Portable builds reject shim executables and verify each bundled tool with
  `-version` before publishing.

## Added

- Preset-owned controls are grayed out with a hover explanation. Click
  **Unlock** next to the preset list to keep the current values and edit them.
- **Settings → System → Mouse wheel adjusts values** (off by default) controls
  whether the wheel can change combo boxes and spin boxes.

## Changed

- New installations start with the **MP4** container.
- Audio stream selection defaults to **all**.
- AMF quality now uses native `-rc qvbr -qvbr_quality_level` arguments instead
  of a generic `-crf` flag. NVENC and QSV keep their original Axiom arguments.

## Portable package

Extract the whole `AxiomPy-0.2.1-win64.zip` folder and run
`AxiomPy\AxiomPy.exe`. Keep `_internal` next to the executable; the bundled
FFmpeg tools live there.

Verify the download:

```powershell
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.1-win64.zip
```

## Validation

- Test suite: `347 passed, 4 skipped`
- Opt-in real FFmpeg conversions: `4 passed`, including H.264 and HEVC NVENC
- 13 native Windows screenshot pages passed the pixel-regression comparison
- C# golden commands remain byte-identical, with a documented AMF QVBR
  correction

## Requirements and limitations

- Windows 10 or Windows 11.
- NVENC/QSV/AMF availability depends on the installed GPU, driver and FFmpeg
  runtime.
- The release is unsigned and does not include an installer.
