# AxiomPy 0.2.2

AxiomPy 0.2.2 improves preset discoverability and fixes the bundled FFmpeg /
NVIDIA driver compatibility failure.

## Preset UI

- Selecting a preset now shows a persistent hint above the Input/Output panel.
- Preset-owned controls are grayed out and explain the reason on hover.
- **Unlock** keeps the current preset values while allowing edits.
- The hint disappears after unlocking or selecting the manual `Preset` entry.

## FFmpeg / NVENC compatibility

The portable package now bundles **FFmpeg 7.1.1** instead of FFmpeg 8.x.
FFmpeg 7.1.1 uses NVENC API **13.0**, which works with NVIDIA driver **570.00 or
newer**. FFmpeg 8.x targets API 13.1 and requires driver 610+, producing:

```text
Required: 13.1 Found: 13.0
The minimum required Nvidia driver for nvenc is 610.00 or newer
```

The release workflow downloads the pinned archive, verifies its SHA-256 and
checks the extracted `ffmpeg -version` before packaging. If FFmpeg still reports
an API mismatch at runtime, AxiomPy now shows an actionable status message
recommending a driver update or x264/x265 fallback.

Drivers older than 570.00 can still use x264/x265, or point
**Settings → FFmpeg** at a custom compatible build.

## Portable package

Extract the whole `AxiomPy-0.2.2-win64.zip` folder and run
`AxiomPy\AxiomPy.exe`. Keep `_internal` next to the executable; the bundled
tools live there.

```powershell
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.2-win64.zip
```

## Validation

- Test suite: `349 passed, 4 skipped`
- Real FFmpeg conversions with 7.1.1: `4 passed`, including H.264 and HEVC NVENC
- 13 native Windows screenshot pages matched at `0.0000%`
- C# golden commands remain byte-identical, with the documented AMF QVBR
  correction

## Requirements and limitations

- Windows 10 or Windows 11.
- Bundled FFmpeg 7.1.1; NVENC requires driver 570.00 or newer.
- QSV/AMF availability depends on the installed GPU and driver runtime.
- The release is unsigned and does not include an installer.
