# AxiomPy 0.2.0

The first public AxiomPy release: a Python/PySide6 desktop frontend for building,
reviewing and running FFmpeg commands on Windows.

## Highlights

- Video, audio, subtitle, container, filter and output-naming controls.
- Software and hardware encoding, including NVENC, QSV and AMF codec families.
- CRF, VBR, CBR, lossless, 1-pass and 2-pass workflows.
- External audio/subtitle muxing, stream metadata and subtitle burn-in.
- Batch queue with per-file status tracking.
- Editable scripts, progress, cancellation and optional external console.
- 1280x720 default layout with 8-16 pt interface scaling.
- Optional workspace restoration covering geometry, docks, tabs, script and parameters.
- English and Simplified Chinese README.

## Portable package

The release asset contains a self-contained Windows onedir package with FFmpeg,
FFprobe and FFplay. Extract `AxiomPy-0.2.0-win64.zip`, then run
`AxiomPy\AxiomPy.exe`.

Verify the download with the adjacent `.sha256` file:

```powershell
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.0-win64.zip
```

## Validation

- Python test suite: `342 passed, 2 skipped`
- Opt-in real FFmpeg conversions: `2 passed`
- Four hardware-command oracle cases match the original C# implementation
- 13 native Windows screenshot pages matched at `0.0000%`
- Windows CI matrix: Python 3.9 and 3.12

## Requirements and limitations

- Windows 10 or Windows 11.
- QSV/AMF availability depends on the installed GPU runtime and drivers.
- YouTube/yt-dlp download support is intentionally not included.
- This release is unsigned and does not include an installer.
