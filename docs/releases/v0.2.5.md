# AxiomPy 0.2.5

AxiomPy 0.2.5 fixes invalid FFmpeg scale filters emitted by some size presets and
makes batch progress reporting reliable at completion.

## Size preset scaling

- Selecting a size such as **1080p** now resolves its standard dimensions even
  though the width and height fields are locked by the preset.
- Combining **1080p** with **lanczos** now generates
  `scale=1920:-2:flags=lanczos` instead of the invalid
  `scale=:-2:flags=lanczos`.
- The same correction applies to UHD and Blu-ray presets that previously left
  the locked width empty.
- Full Screen mode uses the preset height when its locked field is empty.

## Batch progress

- Aggregate batch progress no longer moves backward when the final progress
  poll races with a partial report.
- Completed batch conversions now reliably finish at 100%.

## Portable package

Two archives are published:

- `AxiomPy-0.2.5-win64.zip` includes FFmpeg 7.1.1, FFprobe and FFplay.
- `AxiomPy-0.2.5-win64-noffmpeg.zip` omits those tools. Put a real FFmpeg
  `bin` directory on `PATH` or select the executables in **Settings → Config**.

Both archives extract to an `AxiomPy` folder. Run `AxiomPy\AxiomPy.exe`; in the
full package keep `_internal` next to the executable.

```powershell
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.5-win64.zip
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.5-win64-noffmpeg.zip
```

## Validation

- Test suite: `458 passed, 9 skipped`
- Real FFmpeg 7.1.1 conversions: `9 passed`
- 15 native Windows screenshots matched
- PyInstaller 6.22.3 build passed
- Both portable packages passed `packaging\verify.ps1`, including the startup
  smoke test

## Requirements and limitations

- Windows 10 or Windows 11.
- Python 3.9 through 3.13 for source installs.
- Bundled FFmpeg 7.1.1; NVENC requires NVIDIA driver 570.00 or newer.
- QSV/AMF availability depends on the GPU and driver runtime.
