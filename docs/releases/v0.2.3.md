# AxiomPy 0.2.3

AxiomPy 0.2.3 makes Custom quality rate-control generation predictable and
extends the preset hint system to parameter-level presets and settings paths.

## Custom quality

- User-entered CRF, bitrate, min/max rate and buffer size values are preserved
  when controls are resolved.
- Bare rate numbers are treated as kilobits: `4500` becomes `4500K`.
- Selecting Custom starts on the `CRF` pass. Bitrate is preserved as `-b:v`
  and does not create Max Rate or Buffer Size arguments on its own. A supplied
  Max Rate is clamped to at least Bitrate and receives a default buffer when
  Buffer Size is empty. x264/x265 still prioritize CRF over the bitrate target.
- In `1 Pass` / `2 Pass`, VBR checked uses average bitrate (`-b:v`); VBR
  unchecked emits CBR defaults (`-minrate`/`-maxrate` plus a buffer) when no
  explicit limits are supplied.
- In CRF mode, a supplied Max Rate plus its buffer act as VBV limits. Min Rate
  is used in 1-pass/2-pass VBR/CBR and is disabled on the CRF pass, where
  FFmpeg has no minimum-bitrate target. These limits reach software and
  NVENC/AMF/QSV commands where supported.
- `2 Pass` ignores CRF because FFmpeg does not allow CRF with two-pass encoding;
  CRF and VBR controls are disabled with explanatory tooltips when the selected
  pass cannot use them.
- Image codecs use `-q:v` for the Custom quality value.
- Switching from a named quality to Custom clears stale values once; later pass
  or VBR changes keep the user's edits.

## Presets and parameter hints

- The persistent hint now covers video quality, optimization, size and audio
  quality presets, not only the Input/Output preset list.
- Disabled labels and controls are grayed together and explain the controlling
  preset on hover.
- Top-level preset values still have the **Unlock** action.

## Settings paths

- FFmpeg, FFprobe and FFplay rows show the resolved executable below `<auto>`.
- Each row has **Browse…** and **Auto** buttons.
- Log File has a **Browse…** button.

## Portable package

Extract the whole `AxiomPy-0.2.3-win64.zip` folder and run
`AxiomPy\AxiomPy.exe`. Keep `_internal` next to the executable.

```powershell
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.3-win64.zip
```

## Requirements and limitations

- Windows 10 or Windows 11.
- Bundled FFmpeg 7.1.1; NVENC requires NVIDIA driver 570.00 or newer.
- QSV/AMF availability depends on the GPU and driver runtime.
