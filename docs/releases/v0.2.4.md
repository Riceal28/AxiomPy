# AxiomPy 0.2.4

AxiomPy 0.2.4 restores dock recoverability and refreshes the CI and packaging
toolchain while keeping Python 3.9 support.

## Dock recovery

- A new **View** menu lists **Script Panel**, **Log Panel** and **Batch Queue**.
- Closing any of those docks no longer makes it unreachable.
- The same menu restores docks that were hidden by a saved workspace.
- Menu styling follows the Axiom Dark theme.

## Build and CI

- Updated `actions/checkout` to v7 and `actions/setup-python` to v7.
- Updated PyInstaller to 6.22.3.
- Dependency update PRs requiring Python 3.10 or newer were intentionally not
  merged because the project still supports Python 3.9.

## Portable package

Two archives are published:

- `AxiomPy-0.2.4-win64.zip` includes FFmpeg 7.1.1, FFprobe and FFplay. This is
  the recommended self-contained package.
- `AxiomPy-0.2.4-win64-noffmpeg.zip` omits those tools. Put a real FFmpeg
  `bin` directory on `PATH` or select the executables in **Settings → Config**.

Both archives extract to an `AxiomPy` folder. Run `AxiomPy\AxiomPy.exe`; in the
full package keep `_internal` next to the executable.

```powershell
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.4-win64.zip
Get-FileHash -Algorithm SHA256 .\AxiomPy-0.2.4-win64-noffmpeg.zip
```

## Validation

- Test suite: `456 passed, 9 skipped`
- Real FFmpeg 7.1.1 conversions: `9 passed`
- 15 native Windows screenshots matched at `0.0000%`
- PyInstaller 6.22.3 build passed
- Both portable packages passed `packaging\verify.ps1`, including the startup
  smoke test

## Requirements and limitations

- Windows 10 or Windows 11.
- Python 3.9 through 3.13 for source installs.
- Bundled FFmpeg 7.1.1; NVENC requires NVIDIA driver 570.00 or newer.
- QSV/AMF availability depends on the GPU and driver runtime.
